# 2026.260.0930 — feat(marketplace): emit the R0 dispatcher + opencode skills index

## Summary

The marketplace generator now projects two additional corpus artifacts:

- **`DISPATCHER.md`** — the R0 skill-dispatcher table, generated from each skill
  entity's `triggers:` list, rows pointing at the canonical
  `/charly-<family>:<name>` reference. A consuming repo copies the fragment
  between the stable `BEGIN/END GENERATED SKILL DISPATCHER` markers, so the table
  is single-sourced rather than hand-maintained prose. `type: agent` entities and
  skills with no `triggers:` contribute no row, so authoring can proceed
  incrementally without breaking generation.
- **`.well-known/skills/index.json`** — the opencode `skills.urls` index
  (`name` + `files` + `version` per skill), the manifest for the flat per-skill
  tree the marketplace Pages mirror assembles.

Both are registered in the prune boundary (`scanGenerated`) and covered by the
generate/drift fixture tests.
