# 2026.296.1151 — refactor(marketplace): the corpus reads authored bodies through candywalk's ONE authority (sdk#456)

## Summary

**The corpus generator now reads authored bodies through `candywalk`'s ONE authority instead of
carrying its own copy of "where does a `skill:` node's body live" — the second caller of the
resolution opencharly/sdk#463 put in the shared kit.**

opencharly/sdk#456 was a drift between three encodings of one rule: `deploykit`'s collector
resolved `.agents/skills` for every node (wrong), while this generator held the correct rule
**twice** — a `type: agent` branch in `skillfile.go`'s read path and the same branch in
`extract.go`'s write path — and used the classifier again in four emission decisions. sdk#463 made
`candywalk` the authority (`ShapeOf` / `ReadNodeBody` / `NodeBodyLocation`); this PR makes the
corpus consume it, which is what "one authority, both callers" means. Nothing is left in this repo
that decides where a body lives.

- **`fillSkillFromFile`** reads through `candywalk.ReadNodeBody` and reconciles the node against
  the file. **`fillAgentFromFile` is DELETED** — the agent shape needs no branch: `AuthoredBody`
  carries it, its `References` are empty by construction, and the one reconciliation serves both
  classes.
- **`extract`** asks `candywalk.ShapeOf` for its destination, and the four emission decisions
  (kimi manifest, R0 dispatcher ×2, opencode index, the skill/agent synthesis) ask the same
  function instead of comparing the raw `type:` string.
- **The "no body" message** names the shape's own file (`candywalk.NodeBodyLocation`), so an
  `agent` node can no longer be told to look under `.agents/skills` — the misdirection that made
  sdk#456's red gate unfixable for the author reading it.
- **Pin:** `github.com/opencharly/sdk` v0.2026289.157 → **v0.2026296.1141**, the tag sdk#463's
  merge minted. `go mod tidy` also advances the grpc/protobuf/genproto transitives that pin
  requires.

The change is a consolidation, and the invariant is that the corpus does not move: proven at the
emitted-artifact boundary below, byte for byte.
