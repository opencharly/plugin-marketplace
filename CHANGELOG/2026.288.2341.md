## The diff's remaining fields, named (A1)

**Every step in both recipes carries `in_container: false`, and `id:` on each.** *`in_container` is the step's venue selector; `false` means the step runs on the HOST rather than inside the built image.* **It is `false` for all four steps because both recipes are host-side maintenance:** *the drift comparison reads this checkout's tree against a marketplace corpus on the host, the `git status` half is a host git query, and both pin assertions are `git ls-remote` against a remote — none of them has anything to say inside a built container.* *The `id:`s (`drift-noop`, `tree-committed`, `pin-var-current`, `pin-literal-current`) are the handles a failing step reports under, which is how the pasted output above can name which half failed.*
