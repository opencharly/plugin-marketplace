# 2026.319.1409 — fix(deps): adopt sdk v0.2026319.1356 — the corpus walk skips-and-warns

## Summary

Adopts `opencharly/sdk v0.2026319.1356`, which lands the **skip-and-warn** contract this generator
needs: one unresolvable ref anywhere in the ~2000-ref transitive closure is now a WARNING that costs
that ref's entities, instead of aborting the entire corpus walk.

Without it this generator cannot run at all: `pod-crabbox:v2026.274.0652` was deleted from its repo
(its commit no longer exists — `gh api …/commits/<sha>` → `422`, and that repo's history now starts
at 2026.307), and ~230 corpus sources pin refs transitively, so that single stale pin kept
`charly marketplace generate` red for five days (`opencharly/marketplace#613`).
