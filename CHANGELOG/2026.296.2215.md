# 2026.296.2215 — chore(deps): adopt sdk v0.2026296.2152 — the candywalk declared-refs release

## Summary

Adopt `github.com/opencharly/sdk v0.2026296.2152` — the release of the `candywalk` ref-collector fix
(`opencharly/sdk#467`, tag `v0.2026296.2152`). `collectRefs` now reads a manifest's DECLARED refs off
its scalar nodes and skips block scalars, so a runtime fixture embedded in a `command:` body
(`plugin-box`'s `box-reconcile-closure-reports-unfetchable` bed) no longer kills the corpus walk
(`opencharly/sdk#455`).

This is the producer-first consumer bump: without it the marketplace shim builds the generator
against a `candywalk` that still parses raw bytes, and the refs cutover's `generate` cannot run.

File-by-file:

- `candy/plugin-marketplace/go.mod` — the `require github.com/opencharly/sdk` pin moves
  `v0.2026296.1141 → v0.2026296.2152`.
- `candy/plugin-marketplace/go.sum` — the two sums for that module version (h1 + the Go-module go.mod
  sum), verified by `go mod tidy`.

No source file changes: the plugin already calls `candywalk.CollectEntitiesRemote`, and the fix is
inside that call. Nothing else needed a code change, which is why the diff is two lines of module
metadata.
